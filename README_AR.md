# Bot Center V2

منصة عربية لإدارة بوتات Telegram من لوحة تحكم واحدة.

## أهداف المشروع
- واجهة عربية RTL ومتجاوبة مع الهاتف.
- حساب مستقل لكل مستخدم مع عزل بياناته.
- ربط بوتات Telegram والتحقق من صلاحياتها.
- لوحة مطور وإحصائيات وإدارة المستخدمين.
- اشتراكات بأسعار ومدد يحددها المشغّل.
- دعم Telegram Stars والتحويل المصرفي وطرق الدفع المحلية.
- تخزين دائم وآمن للبيانات والأسرار.

## الأمان
لا تضع Bot Token أو مفاتيح API أو كلمات مرور داخل ملفات Git. استخدم متغيرات البيئة في الاستضافة.

## ملاحظة
هذا المستودع مخصص للنسخة الجديدة، ولا يغيّر المستودع القديم. التطبيق لم يُرفع بعد؛ هذا الملف يعرّف بخطة العمل.
